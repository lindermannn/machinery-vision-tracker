# Publicación del proyecto

El responsable autorizó publicar el código propio bajo AGPL-3.0 el 5 de octubre
de 2026. Se incluyen los dos métodos, pruebas, configuración, scripts auxiliares
y capturas y gráficos seleccionados. Los videos completos se excluyen por decisión
expresa posterior del responsable.

No se publican pesos, bases de anotación, documentos de selección, entornos,
credenciales ni rutas personales. Las dependencias conservan sus licencias;
consultar THIRD_PARTY_NOTICES.md.

Antes de publicar se revisan el contenido y el historial, se ejecutan las pruebas
y el verificador de publicación. Los commits nuevos usan identidad del proyecto
sin correo personal. No se reescribe el historial ya público.
